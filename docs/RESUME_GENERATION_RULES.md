## 2. Hard Anti-Fabrication Constraints

1. **Never Fabricate Employment Experience:**
   - Internships must be clearly identified as internships or training.
   - Academic projects must never be relabeled as commercial employment.
2. **Never Invent Numerical Metrics or Revenue:**
   - Do not claim "$50k revenue generated", "100,000 active users", or "reduced latency by 99%" without empirical measurement.
   - Emphasize verified technical mechanisms instead (e.g. "implemented PostGIS ST_DWithin geospatial queries", "utilized PostgreSQL SELECT FOR UPDATE row-level locking to prevent double-booking").
3. **Never Invent Degrees or Certifications:**
   - Forbidden unverified degree terms: B.Tech, B.E., M.Tech, Ph.D, MBA.
   - If a JD requires B.Tech, CareerOS presents candidate's MCA with honesty and highlights computer science foundations.
4. **Never Invent Skills to Boost ATS Score:**
   - If a JD asks for Kubernetes, AWS, or C#, but the candidate profile lacks evidence, CareerOS reports them as **Missing Mandatory Requirements**. The system will never fabricate them.
5. **Action Verbs Grounded in Reality:**
   - Use strong, clear action verbs: *Developed, Implemented, Engineered, Designed, Optimized, Integrated, Secured, Architected*.

## 3. Dynamic Tailoring Boundaries

What CareerOS **is permitted** to tailor:
1. **Summary Hook:** Dynamically focus the opening paragraph on Java Backend, Full Stack, or AI/Python to match the target opening.
2. **Project Prioritization:** Reorder the top 3-4 projects so the most relevant project appears first (e.g. Leave Management for Spring Boot roles; NearVia for Full Stack roles; FinSight / Smart Rover for AI roles).
3. **Technical Skill Grouping:** Position matching languages and tools first within their category lines to accelerate recruiter scanning.
4. **Bullet Refinement:** Highlight relevant architectural aspects (e.g. mentioning transactional integrity for enterprise backend roles).

---

## 5. Single-Page Physical Geometry & Margin Standards

To guarantee that freshers' ATS resumes never bleed 2-3 lines onto an accidental second page:
1. **Zero Double Margins:** Never combine non-zero `@page { margin: ... }` in CSS with non-zero Playwright margin parameters. In `templateEngine.js`, `@page { size: A4; margin: 0; }` is enforced, and print margins are strictly delegated to Playwright's `page.pdf({ margin: { top: '10mm', right: '12mm', bottom: '10mm', left: '12mm' } })`.
2. **Break Avoidance:** Section blocks apply `break-inside: avoid` so content remains structurally cohesive.
3. **Exact Page Verification:** All compiled PDFs must be verified to have `pageCount === 1` using structural PDF page scanning.

---

## 6. Auditor Verification Gate

Every resume generated by `resumeStudioService.js` is automatically audited by `auditDocumentTruthfulness(content, profile)` before being displayed or compiled:
- Flags any unapproved degree strings.
- Flags any inflated commercial tenure claims (>1 yr).
- Outputs warnings if any ungrounded assertions are detected.
